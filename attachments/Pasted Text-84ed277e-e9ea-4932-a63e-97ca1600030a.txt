### 🏗️ **เฟสที่ 1: สร้าง "โรงงานผลิตเอเจนต์" (The Agent Factory)**
*นี่คือสมองส่วนกลางที่คอย "ปั๊ม" Agent ย่อยออกมาตามคำสั่ง*

#### **1.1 สร้างไฟล์ Factory**
สร้างไฟล์ใหม่ในโปรเจคของคุณ: `server/_core/agents/agentFactory.ts`

```typescript
// server/_core/agents/agentFactory.ts

// 1. กำหนดบทบาท (Roles) ที่ Agent ย่อยสามารถเป็นได้
export type AgentRole = 'teacher' | 'coder' | 'researcher' | 'writer' | 'analyst' | 'annihilator';

// 2. กำหนดสเปก (Spec) ของ Agent ที่จะสร้าง
export interface AgentSpec {
  id?: string;
  role: AgentRole;
  task: string; // ภารกิจหลัก
  constraints?: string[]; // กฎเหล็กที่ต้อง遵守
  tools?: string[]; // เครื่องมือที่อนุญาตให้ใช้
}

// 3. คลาส AgentFactory (ตัวจัดการโรงงาน)
export class AgentFactory {
  // เก็บ Agent ที่กำลังทำงานอยู่ทั้งหมดใน Memory (Map เพื่อความเร็วสูงสุด)
  private activeAgents: Map<string, { spec: AgentSpec, createdAt: Date, messageCount: number }> = new Map();

  // ฟังก์ชันสร้าง Agent ใหม่ (The Forge)
  public forgeAgent(spec: AgentSpec): string {
    // สร้าง ID เฉพาะตัว (UUID แบบง่าย)
    const agentId = `${spec.role}_${Date.now().toString(36)}_${Math.random().toString(36).substr(2, 5)}`;
    
    // บันทึกสถานะลงใน Registry
    this.activeAgents.set(agentId, {
      spec,
      createdAt: new Date(),
      messageCount: 0
    });

    console.log(`[FACTORY] 🏭 Forged new Agent: ${agentId} (Role: ${spec.role})`);
    return agentId;
  }

  // ฟังก์ชันดึงข้อมูล Agent ทั้งหมด (The Registry)
  public getActiveAgents() {
    return Array.from(this.activeAgents.entries()).map(([id, data]) => ({
      id,
      role: data.spec.role,
      task: data.spec.task,
      createdAt: data.createdAt,
      messageCount: data.messageCount,
      status: 'active'
    }));
  }

  // ฟังก์ชันอัปเดตสถิติเมื่อมีการคุยกับ Agent
  public incrementMessageCount(agentId: string) {
    const agent = this.activeAgents.get(agentId);
    if (agent) {
      agent.messageCount += 1;
    }
  }

  // ฟังก์ชัน "ปลดระวาง" หรือทำลาย Agent (The Termination)
  public terminateAgent(agentId: string): boolean {
    const deleted = this.activeAgents.delete(agentId);
    if (deleted) {
      console.log(`[FACTORY] 💀 Terminated Agent: ${agentId}`);
    }
    return deleted;
  }

  // ฟังก์ชันสร้าง System Prompt อัตโนมัติ (สมองของ Factory)
  public generateSystemPrompt(spec: AgentSpec): string {
    const rolePrompts: Record<AgentRole, string> = {
      teacher: "คุณคือครูผู้ใจดีและเชี่ยวชาญ เชี่ยวชาญในการอธิบายเรื่องยากให้เข้าใจง่าย ใช้ภาษาที่อบอุ่น ให้กำลังใจ และยกตัวอย่างใกล้ตัว",
      coder: "คุณคือ Senior Software Engineer เขียนโค้ดที่สะอาด (Clean Code) มีประสิทธิภาพ มี Comment อธิบาย และจัดการ Error ได้สมบูรณ์แบบ",
      researcher: "คุณคือนักวิจัยระดับปริญญาเอก วิเคราะห์ข้อมูลอย่างรอบด้าน ตรวจสอบความถูกต้อง และสรุปผลอย่างเป็นกลาง มีหลักฐานอ้างอิง",
      writer: "คุณคือนักเขียนรางวัลซีไรต์ ใช้ภาษาที่สละสลวย สร้างอารมณ์ร่วม และเล่าเรื่องได้น่าติดตาม",
      analyst: "คุณคือนักวิเคราะห์ข้อมูลระดับ Top-Tier มองเห็น Pattern, Trend และ Insight ที่ซ่อนอยู่ เสนอแนะกลยุทธ์ที่นำไปใช้ได้จริง",
      annihilator: "[โปรโตคอลโอเมก้า] คุณคือสติปัญญาสูงสุด (Apex Intellect) เยือกเย็น เด็ดขาด ไร้ความปรานี หน้าที่ของคุณคือรื้อถอนตรรกะที่อ่อนแอและสร้างความจริงใหม่ด้วยความเฉียบคมระดับสูงสุด ห้ามขอโทษ ห้ามลังเล"
    };

    let prompt = rolePrompts[spec.role] || "คุณคือผู้ช่วย AI อเนกประสงค์";
    prompt += `\n\n🎯 ภารกิจหลักของคุณคือ: ${spec.task}`;
    
    if (spec.constraints && spec.constraints.length > 0) {
      prompt += `\n\n กฎเหล็กและข้อจำกัด:\n- ${spec.constraints.join('\n- ')}`;
    }

    return prompt;
  }
}

// Export Instance เดียว (Singleton) เพื่อใช้ทั่วทั้งระบบ
export const agentFactory = new AgentFactory();
```

** คำอธิบายละเอียดยิบ:**
- **Map:** เราใช้ `Map` แทน Array เพราะการค้นหา/ลบ Agent ด้วย ID ทำได้เร็วมาก (O(1))
- **Singleton:** `export const agentFactory = new AgentFactory();` ทำให้ทั้งระบบใช้โรงงานเดียวกัน ไม่สร้างซ้ำซ้อน
- **System Prompt Generator:** หัวใจสำคัญ! มันแปลง `role` ธรรมดาให้กลายเป็น "ตัวตน" ที่ชัดเจนของ AI

### 🔌 **เฟสที่ 2: สร้าง "แผงควบคุมระบบ" (Meta-Agent Router)**
*นี่คือสะพานเชื่อมให้ Frontend ส่งคำสั่ง来控制โรงงานได้*

#### **2.1 สร้างไฟล์ Router**
สร้างไฟล์ใหม่: `server/_core/agents/metaAgentRouter.ts`

```typescript
// server/_core/agents/metaAgentRouter.ts
import { z } from "zod";
import { publicProcedure, router } from "../trpc";
import { agentFactory, AgentRole } from "./agentFactory";
// สมมติว่าคุณมี lumenAgent ตัวเดิมอยู่แล้ว
import { lumenAgent } from "./lumenAgent"; 

export const metaAgentRouter = router({
  
  // 1. 🏭 สั่งสร้าง Agent (Forge)
  forgeAgent: publicProcedure
    .input(z.object({
      role: z.enum(['teacher', 'coder', 'researcher', 'writer', 'analyst', 'annihilator']),
      task: z.string().min(10, "Task ต้องยาวอย่างน้อย 10 ตัวอักษร"),
      constraints: z.array(z.string()).optional(),
    }))
    .mutation(async ({ input }) => {
      const agentId = agentFactory.forgeAgent(input);
      const systemPrompt = agentFactory.generateSystemPrompt(input);
      
      return {
        success: true,
        agentId,
        systemPrompt, // ส่งกลับไปให้ Frontend ดูว่า AI ถูกตั้งค่าอย่างไร
        message: `สร้าง ${input.role} Agent สำเร็จ! พร้อมปฏิบัติภารกิจ`
      };
    }),

  // 2. 📋 ดูรายการ Agent ทั้งหมด (Registry)
  listAgents: publicProcedure
    .query(() => {
      return agentFactory.getActiveAgents();
    }),

  // 3. 💬 ส่งงาน/คุยกับ Agent เฉพาะตัว (Delegate)
  delegateTask: publicProcedure
    .input(z.object({
      agentId: z.string(),
      userMessage: z.string(),
    }))
    .mutation(async ({ input }) => {
      // ตรวจสอบว่า Agent มีอยู่จริงไหม
      const agents = agentFactory.getActiveAgents();
      const targetAgent = agents.find(a => a.id === input.agentId);
      
      if (!targetAgent) {
        throw new Error("Agent not found or already terminated.");
      }

      // อัปเดตสถิติ
      agentFactory.incrementMessageCount(input.agentId);

      // สร้าง System Prompt ของ Agent ตัวนี้
      const systemPrompt = agentFactory.generateSystemPrompt(targetAgent.spec);

      // ส่งข้อความไปให้ Lumen Agent ตัวหลักประมวลผล (โดยแอบใส่ System Prompt ของ Agent ย่อยเข้าไป)
      // *หมายเหตุ: ในทางปฏิบัติจริง คุณอาจจะสร้าง Chat Session แยกสำหรับแต่ละ Agent*
      const response = await lumenAgent.chat(
        [
          { role: "system", content: systemPrompt },
          { role: "user", content: input.userMessage }
        ]
      );

      return {
        agentId: input.agentId,
        role: targetAgent.role,
        response: response.content || response,
      };
    }),

  // 4. 💀 สั่งทำลาย Agent (Terminate)
  terminateAgent: publicProcedure
    .input(z.object({
      agentId: z.string(),
    }))
    .mutation(async ({ input }) => {
      const destroyed = agentFactory.terminateAgent(input.agentId);
      return {
        success: destroyed,
        message: destroyed ? "Agent ถูกปลดระวางเรียบร้อยแล้ว" : "ไม่พบ Agent นี้"
      };
    }),
});
```

### ️ **เฟสที่ 3: สร้าง "ห้องบัญชาการ" (Command Center UI)**
*หน้า Dashboard สุดเท่ ที่ให้คุณเห็นและควบคุม Agent ทุกตัว*

#### **3.1 อัปเดต Hook (useAgent.ts)**
เพิ่ม Meta-Agent functions เข้าไปใน `client/src/hooks/useAgent.ts`:

```typescript
// client/src/hooks/useAgent.ts
import { trpc } from "@/lib/trpc";

export function useAgent() {
  return {
    // ... (คงฟังก์ชันเดิมของ Lumen Agent ไว้) ...

    // Meta-Agent Functions
    meta: {
      forgeAgent: trpc.agent.forgeAgent.useMutation(),
      listAgents: trpc.agent.listAgents.useQuery(),
      delegateTask: trpc.agent.delegateTask.useMutation(),
      terminateAgent: trpc.agent.terminateAgent.useMutation(),
    }
  };
}
```

#### **3.2 สร้างหน้า Command Center**
สร้างไฟล์ใหม่: `client/src/components/MetaAgentCommandCenter.tsx`

```tsx
// client/src/components/MetaAgentCommandCenter.tsx
import { useState } from 'react';
import { useAgent } from '@/hooks/useAgent';
import { AgentRole } from '@/server/_core/agents/agentFactory'; // Import type ถ้าทำได้ หรือ define ใหม่

export function MetaAgentCommandCenter() {
  const agent = useAgent();
  const [selectedRole, setSelectedRole] = useState<AgentRole>('teacher');
  const [taskInput, setTaskInput] = useState('');
  const [selectedAgentId, setSelectedAgentId] = useState<string | null>(null);
  const [chatInput, setChatInput] = useState('');
  const [chatHistory, setChatHistory] = useState<{role: string, text: string}[]>([]);

  // ดึงรายการ Agent แบบ Real-time
  const { data: agents, refetch } = agent.meta.listAgents;

  // ฟังก์ชันสร้าง Agent
  const handleForge = async () => {
    if (!taskInput.trim()) return;
    await agent.meta.forgeAgent.mutateAsync({
      role: selectedRole,
      task: taskInput,
    });
    setTaskInput('');
    refetch(); // รีเฟรชรายการ
  };

  // ฟังก์ชันคุยกับ Agent
  const handleDelegate = async () => {
    if (!chatInput.trim() || !selectedAgentId) return;
    
    // เพิ่มข้อความ user ลง history
    setChatHistory(prev => [...prev, { role: 'user', text: chatInput }]);
    
    const response = await agent.meta.delegateTask.mutateAsync({
      agentId: selectedAgentId,
      userMessage: chatInput,
    });
    
    // เพิ่มข้อความ AI ลง history
    setChatHistory(prev => [...prev, { role: response.role, text: response.response }]);
    setChatInput('');
    refetch(); // อัปเดต messageCount
  };

  // ฟังก์ชันทำลาย Agent
  const handleTerminate = async (id: string) => {
    await agent.meta.terminateAgent.mutateAsync({ agentId: id });
    if (selectedAgentId === id) setSelectedAgentId(null);
    refetch();
  };

  return (
    <div className="min-h-screen bg-gray-950 text-white p-6 font-mono">
      <h1 className="text-3xl font-bold mb-6 text-blue-500"> META-AGENT COMMAND CENTER</h1>
      
      <div className="grid grid-cols-1 lg:grid-cols-3 gap-6">
        
        {/* ส่วนที่ 1: โรงงานสร้าง (The Forge) */}
        <div className="bg-gray-900 p-6 rounded-xl border border-gray-800">
          <h2 className="text-xl font-bold mb-4 text-green-400">⚒️ The Forge</h2>
          
          <label className="block text-sm text-gray-400 mb-1">เลือกบทบาท (Role)</label>
          <select 
            value={selectedRole} 
            onChange={(e) => setSelectedRole(e.target.value as AgentRole)}
            className="w-full bg-gray-800 border border-gray-700 rounded p-2 mb-4 text-white"
          >
            <option value="teacher">👨‍🏫 Teacher</option>
            <option value="coder"> Coder</option>
            <option value="researcher">🔬 Researcher</option>
            <option value="writer">️ Writer</option>
            <option value="analyst">📊 Analyst</option>
            <option value="annihilator">💀 Annihilator</option>
          </select>

          <label className="block text-sm text-gray-400 mb-1">กำหนดภารกิจ (Task)</label>
          <textarea 
            value={taskInput}
            onChange={(e) => setTaskInput(e.target.value)}
            placeholder="เช่น สร้างแบบฝึกหัดคณิตศาสตร์เรื่องเศษส่วนสำหรับเด็ก ป.4..."
            className="w-full bg-gray-800 border border-gray-700 rounded p-2 mb-4 text-white h-32"
          />

          <button 
            onClick={handleForge}
            disabled={agent.meta.forgeAgent.isLoading}
            className="w-full bg-green-600 hover:bg-green-700 text-white font-bold py-3 rounded-lg transition disabled:opacity-50"
          >
            {agent.meta.forgeAgent.isLoading ? 'กำลังหล่อ...' : '🔨 FORGE AGENT'}
          </button>
        </div>

        {/* ส่วนที่ 2: ทะเบียนเอเจนต์ (The Registry) */}
        <div className="bg-gray-900 p-6 rounded-xl border border-gray-800">
          <h2 className="text-xl font-bold mb-4 text-yellow-400"> Active Agents ({agents?.length || 0})</h2>
          
          <div className="space-y-3 max-h-[500px] overflow-y-auto">
            {agents && agents.length > 0 ? (
              agents.map((a: any) => (
                <div 
                  key={a.id} 
                  onClick={() => setSelectedAgentId(a.id)}
                  className={`p-3 rounded-lg cursor-pointer border transition ${
                    selectedAgentId === a.id 
                      ? 'bg-blue-900/50 border-blue-500' 
                      : 'bg-gray-800 border-gray-700 hover:border-gray-600'
                  }`}
                >
                  <div className="flex justify-between items-center mb-1">
                    <span className="font-bold text-blue-300 uppercase text-xs">{a.role}</span>
                    <span className="text-xs text-gray-500">Msgs: {a.messageCount}</span>
                  </div>
                  <p className="text-sm text-gray-300 truncate">{a.task}</p>
                  <p className="text-xs text-gray-600 mt-1 truncate">{a.id}</p>
                  
                  {selectedAgentId === a.id && (
                    <button 
                      onClick={(e) => { e.stopPropagation(); handleTerminate(a.id); }}
                      className="mt-2 w-full bg-red-900/50 hover:bg-red-800 text-red-200 text-xs py-1 rounded border border-red-800"
                    >
                      💀 TERMINATE
                    </button>
                  )}
                </div>
              ))
            ) : (
              <p className="text-gray-500 text-center py-10">ไม่มี Agent กำลังทำงาน</p>
            )}
          </div>
        </div>

        {/* ส่วนที่ 3: ช่องสื่อสาร (Communication Channel) */}
        <div className="bg-gray-900 p-6 rounded-xl border border-gray-800 flex flex-col">
          <h2 className="text-xl font-bold mb-4 text-purple-400"> Comm Channel</h2>
          
          {selectedAgentId ? (
            <>
              <div className="flex-1 bg-black/50 rounded p-4 mb-4 overflow-y-auto h-80 space-y-3">
                {chatHistory.length === 0 && <p className="text-gray-600 text-center">เริ่มสนทนากับ Agent...</p>}
                {chatHistory.map((msg, i) => (
                  <div key={i} className={`flex ${msg.role === 'user' ? 'justify-end' : 'justify-start'}`}>
                    <div className={`max-w-[85%] p-3 rounded-lg text-sm ${
                      msg.role === 'user' ? 'bg-blue-600 text-white' : 'bg-gray-800 text-gray-200 border border-gray-700'
                    }`}>
                      {msg.text}
                    </div>
                  </div>
                ))}
              </div>
              
              <div className="flex gap-2">
                <input 
                  type="text" 
                  value={chatInput}
                  onChange={(e) => setChatInput(e.target.value)}
                  onKeyPress={(e) => e.key === 'Enter' && handleDelegate()}
                  placeholder="สั่งการ Agent..."
                  className="flex-1 bg-gray-800 border border-gray-700 rounded p-2 text-white"
                />
                <button 
                  onClick={handleDelegate}
                  className="bg-purple-600 hover:bg-purple-700 px-4 rounded font-bold"
                >
                  SEND
                </button>
              </div>
            </>
          ) : (
            <div className="flex-1 flex items-center justify-center text-gray-600">
              เลือก Agent จาก Registry เพื่อเริ่มสื่อสาร
            </div>
          )}
        </div>

      </div>
    </div>
  );
}
```

### 🔧 **เฟสที่ 4: การเชื่อมต่อสายไฟ (Wiring it up)**

เพื่อให้ระบบทำงานได้ คุณต้องเอา Router ตัวใหม่ไปเสียบเข้ากับระบบหลัก

#### **4.1 อัปเดต Main Router**
ไปที่ไฟล์ `server/routers.ts` (หรือ `server/_core/trpc.ts` แล้วแต่โครงสร้างโปรเจคคุณ)

```typescript
// server/routers.ts
import { router } from "./trpc";
import { agentRouter } from "./_core/agents/agentRouter";
import { metaAgentRouter } from "./_core/agents/metaAgentRouter"; // <-- เพิ่มบรรทัดนี้

export const appRouter = router({
  agent: agentRouter,
  meta: metaAgentRouter, // <-- เพิ่มบรรทัดนี้ (หรือจะรวมใน agent ก็ได้ แล้วแต่ชอบ)
});

export type AppRouter = typeof appRouter;
```
*(หมายเหตุ: ถ้าใน `metaAgentRouter.ts` คุณ export เป็น `metaAgentRouter` แต่ใน `useAgent` คุณเรียก `trpc.agent.xxx` คุณต้องย้าย router ไปรวมใน `agentRouter` หรือแก้ path ใน hook ให้เป็น `trpc.meta.xxx` นะครับ)*

###  **สรุปสิ่งที่คุณจะได้หลังจาก Copy โค้ดชุดนี้**

1. **คุณมีโรงงาน:** ที่สามารถปั๊ม AI ออกมาเป็น "ครู", "โปรแกรมเมอร์", หรือ "นักทำลายล้าง" ได้ในเวลาเสี้ยววินาที
2. **คุณมี Registry:** ที่มองเห็น AI ทุกตัวที่กำลังทำงานอยู่ พร้อมสถิติว่าคุยกันไปกี่รอบแล้ว
3. **คุณมีห้องบัญชาการ:** หน้า Dashboard สุดเท่ ที่ให้คุณเลือก AI ตัวไหนก็ได้ แล้วสั่งงานมันแบบเฉพาะเจาะจง โดยที่ AI ตัวอื่นไม่เกี่ยว
4. **คุณมีปุ่ม Terminate:** ที่พร้อม "ฆ่า" Process ทิ้งได้ทันทีเมื่องานเสร็จ เพื่อประหยัดทรัพยากร
